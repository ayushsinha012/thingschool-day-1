=== Why SQL public network access remains Enabled ===
This subscription enforces a hard, subscription-wide limit of one
Container Apps environment (MaxNumberOfGlobalEnvironmentsInSubExceeded -
see evidence/architecture.txt for the actual error). The one environment
that exists, thinkschool-env, has no VNet integration and cannot be given
VNet integration after creation. The MaintainXpert API Container App
therefore runs in thinkschool-env and reaches Azure SQL over the public
endpoint, not the private one. Disabling public network access would
sever the only connection path the deployed API actually has. The private
endpoint above is real and independently verified (Approved connection
state, correct target resource, correct private IP, working DNS
resolution, and a real TCP connect test from inside the VNet - see
evidence/private-endpoint-connectivity-test.txt) - this is reported as a
residual, honestly documented limitation, not a completed mitigation.
