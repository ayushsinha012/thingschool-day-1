BackgroundService vs IHostedService vs Hangfire

BackgroundService
Base class used above (BackgroundJobWorker) - override ExecuteAsync with a long-running loop. Ideal for a queue consumer like this one.
IHostedService
The lower-level interface BackgroundService implements (StartAsync/StopAsync). Used directly only when startup/shutdown need explicit control beyond one ExecuteAsync loop - not needed here, so this app doesn't implement it directly.
Hangfire
Adds what the queue above doesn't have: persistence, retries, scheduling, and a dashboard. This API runs one recurring job on it (purges finished job records older than 10 minutes, every minute) - open the dashboard.
